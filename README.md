# 📱 NEXUS PHONE STUDIO
### *Boutique Smartphone Showroom & In-Store Pickup Experience*

A sleek, responsive, and ultra-clean smartphone showroom web application built with Flipkart & Meesho-inspired product specifications and an Apple-grade minimalist user experience.

---

## ✨ Key Improvements & Design Highlights

1. **100% English Content**:
   - Clean, professional, and clear product copy, specifications, and showroom policies.

2. **Unified Navigation ("Explore Menu" Drawer)**:
   - The top navigation bar is decluttered: multiple static links have been replaced by a single, elegant **"Explore Menu"** button that slides open a directory of budget tiers, brands, showroom tools, and timings.

3. **Spacious & Uncluttered Hero Section**:
   - High-impact headline: *"Flagships & Value Kings. Reserve Online. Pick Up In-Store."*
   - Breathable spacing, high contrast, clean quick-filter budget pills (Under ₹15,000, ₹15,000 - ₹30,000, ₹30,000 - ₹60,000, Flagships ₹60,000+).
   - A single, minimal spotlight card for the flagship showcase.

4. **Flipkart & Meesho Inspired Phone Showcase**:
   - **View Mode Switcher**: Toggle between **List View ☰ (Flipkart style)** and **Grid View ⊞**.
   - **Real-World Indian Retail Pricing & Specs**:
     - Flagships: iPhone 16 (₹74,999), Samsung Galaxy S24 Ultra (₹1,19,999)
     - Premium Mid-Range: OnePlus 12R (₹37,999), Vivo V40 Pro (₹49,999)
     - Upper Budget: Nothing Phone 2a (₹23,999), Moto Edge 50 Fusion (₹21,999), Realme 13 Pro (₹24,999)
     - Mass Budget: Redmi Note 13 5G (₹14,999), Samsung Galaxy M15 5G (₹12,499), Moto G45 5G (₹11,999)
   - Verified green ratings badge (`4.8 ★`), detailed bullet-point specs (RAM, ROM, Display cm/inches, Camera OIS, Battery mAh, Fast Charging wattage, Processor, and Official Warranty).
   - Price breakdown: Current Selling Price, Strikethrough M.R.P., Green % Discount, and No-Cost EMI calculation.
   - Showroom Shelf Tracking: (e.g. `Zone A • Shelf 01`, `Zone D • Shelf 04`).

5. **In-Store Pickup Hold Pass (Zero Advance Payment)**:
   - Customer reserves the phone online, picks date & time slot.
   - Generates a verified **Digital Store Pass** with a scannable **QR Code** and **Barcode** for instant counter pickup with zero queuing.

6. **Spot Old-Phone Trade-In Calculator**:
   - Immediate in-store valuation estimate based on model and body condition.

## 🚀 How to Run

No `npm` dependencies required! Open `/Users/apple/Documents/skils/index.html` directly in your browser:
```bash
open /Users/apple/Documents/skils/index.html
```
Or use any local web server:
```bash
python3 -m http.server 8000
```
